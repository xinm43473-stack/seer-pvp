# 精灵筛选与上位替代规则

## 一、收录标准（2026-11-04 修订，F20261104）

**唯一标准：两位 UP 主（蝶夏Channel UID 59224295、不要脸的狗子 UID 287935100）是否出过该精灵的配置／攻略视频或专题作品。**

1. **不再以「单条魂印」为判断条件。** 早期抓取把多段魂印截成第一句（至序圣华仅 41 字，全文 1118 字 / 52 段），「单条／多条」本身不可判定，旧自动剔除理由「单条魂印且无核心机制」全部作废。
2. **不再以种族值或自动评分为判断条件。** 「种族值过低」剔除理由同样作废；`tier / score` 只用于排深研优先级。
3. **唯一依据是配置／攻略专题**：`creator_index.json` 的 `themed_spirits`（培养方案／配置分享／解析／觉醒契约特训篇等）是唯一直接依据。**标题提及（周测评／返场／皮肤／剧情／同人向）不作依据**——用户 2026-11-04 要求「作品提及全部删了，这是巅峰精灵推荐不是同人」，已把 `mentioned_spirits`（562 只）整体删除，连带删除仅靠提及入池的 24 只候选，总表、候选池、复核队列与生成脚本同步过滤。狗子 711 个视频标题被 B 站风控挡住，且作品太杂、无分类合集，用户已决定不再补齐；当前只保留 6 条公开可核验线索，不臆造其余名单。
4. **作废理由可查不硬删**：`data/bwiki/pool.json` 的 `dropped` 仅作历史留痕，两类作废理由对应的 358 只精灵写入 `references/catalog/voided_drops.json`。其中作品覆盖者必须落在 `spirits` 或 `pending_research`；未查到覆盖者保留可查记录，发现作品后立即入池。
5. **无魂印须按 BWIKI 魂印全文复核**，不再沿用自动「无魂印」结论；页面抓取失败／资料缺失只能标「待核验」。
6. **只评 PvP、同 ID 不重复**：纯 PvE 工具人、仅剧情收藏价值者不进推荐库（历史玩法标 `legacy`）；同 ID 多形态用 `forms` 记录，不建两个条目。序号范围仍为 `ID >= 2987`，4000／5000 等特殊编号同样有效。
7. **录入 ≠ 推荐**：先入 `pending_research` 与 `references/docs/candidates.md`，逐只深研后才晋升 `spirits`；明显上位替代与强度只在深研层判断，不作为录入阶段删除依据。

## 二、魂印机制评估（不再按条数筛选）

**魂印条数不是筛选条件**：只用于拆解机制，不用于判断「要不要收录」。不要把分号数量当作独立效果数量。先拆成“触发条件—作用对象—持续时点—收益—反制”五项，再按以下维度评估：

| 维度 | 检查问题 | 高分表现 |
|---|---|---|
| 触发可靠性 | 是否要求特定血量、命中、技能顺序、队友生死或对手配合？ | 主动可控，失败有补偿 |
| 技能组闭环 | 魂印与先手、第五、强化、免控是否互相服务？ | 启动后能持续拿回合或击杀 |
| 团队独特性 | 是否有复活、驱逐、传承、锁切、地图炮等难替代功能？ | 同定位至少一项稀缺价值 |
| 对局覆盖 | 能应对多少主流核心，是否只赢极少数冷门？ | 有常见对局或明确高价值对策 |
| BP 与配置成本 | 是否占限二/限三，是否必须顶配宝石/刻印？ | 与同成本候选相比仍有收益 |
| 反制与容错 | 是否被常见魂免、断回合、消逝、弹伤一跳就停？ | 被针对后仍能提供团队收益 |

满足“当季官方池/高分段数据支持”或“至少一项独特机制 + 可复盘实战”即可保留。仅有文字堆叠、理论上限或单局素材不足以收录为主流。

## 三、明显上位替代（深研强制检查项）

**每只晋升 `spirits` 或进入候选池前，都必须写出上位替代判断结论**：`无上位` / `有上位但保留理由` / `有上位则排除`。只堆机制、不核上位，视为未完成深研。已确认替代表中的旧形态一律不得进入 `spirits` 或 `pending_research`；后续独立形态需写明独立价值才可保留。


同时满足以下条件才判“明显上位”，禁止只因编号更新就删除：

1. 核心定位、主要对位和团队职责高度重合；
2. 新形态在启动、容错、输出或支援上全面更稳定；
3. 旧形态没有独立的魂印/技能组用途；
4. 旧形态也没有低成本、特定规则或特殊套装下的独特价值；
5. 没有当前高分段或可信实战证据支持旧形态。

## 五、低强度删除与例外

- 删除没有可靠启动、没有团队功能、技能组无法兑现魂印且已有同职责上位的精灵。
- **种族值不得作为删除依据**（F20261104）；圣甲·盖亚（3056）、王·雷伊（3142）、冥王·苍月影（3507）等可凭独立机制保留。
- 低强度删除只针对「作品未覆盖、深研后确认无可靠启动／无团队功能／技能组无法兑现魂印且已有同职责上位」者，并需写明证据。
- 对“曾经冷门有趣、当前被同类全面覆盖”的条目标 `excluded` 或 `legacy`，不要混入当前推荐。
- 布蕾里克（4318）因蝶夏契约篇做过专题，按「UP 主作品全量录入」从排除记录转入 `pending_research`，仍不进入默认组队池；僧行、青丘、炎魔之王等保留在研究排除记录。新羁绊、新技能或特定限制池出现后可重新评估。

## 六、版本复核

每次赛季或限制池变化后：

1. 先更新官方池和新技能/觉醒信息；
2. 再看高分段数据，区分“真实退环境”和“被限制池临时压制”；
3. 最后复查冷门，不因单月低出场直接判死；
4. 给所有强度结论写资料日期，未复核时明确“历史结论”。

## 六·补、远古资料的使用边界（2026-11-04）

用户要求「对于远古资料谨慎加入」。**2022 年及以前的强度／环境资料与早期社区线索只作历史机制线索**：

1. 归入远古／历史来源：`H2016`、`B2019LIST`、`B2021TIER`、`B2022BAN`、`P2023LOW` 及早期 B 站视频编号（完整清单见 `roster.json` 的 `review_rules.legacy_markers`）。
2. 引用时必须写年份与适用赛季，标「历史结论」；不得转成永久 T0/T1，也不得作为当前强度证据。
3. 新条目**不得只靠远古资料晋升**；须与「叫颤于不是鳝鱼」的具体月份竞技图鉴、官方限制池或可复盘实战交叉核对。
4. 只靠远古资料支撑的 `meta` 条目会由 `check_roster.py` 报警，需人工复核后降级或补当月证据。
5. 历史玩法可留档并标 `legacy`，但不进入当前上分阵容。

## 七、先入候选池、再深研

用户点名、月度榜新核心或攻略作者（蝶夏Channel、不要脸的狗子等）覆盖但尚未核验的精灵，流程为：

1. **先入列表**：写入 `roster.json` 的 `pending_research`（含编号、属性、来源标记、待核问题）与 `references/docs/candidates.md`；同时维护 `deep_dive_queue`（已入库但说明不足者）。已通过 BWIKI 图鉴接口核到准确编号的条目写整数 ID，名称未命中的写 `null` 并标「待核」，不臆造编号。
2. **候选不等于推荐**：候选池条目尚未过魂印原文与实战价值评估，禁止出现在阵容建议、梯度结论或联动链条里；查询回答时应说明「已记录在候选池、待深研」。
3. **逐只深研**：按 `candidates.md` 的六项检查补机制、证据、上位替代与失效点；`high` 优先级（用户点名）先做。
4. **晋升或排除**：通过者写入 `spirits` 并给出 `status`；不通过者写入 `excluded_examples` 并写明理由；同步更新候选池状态与 `verified_at`。

## 八、攻略作者作品全量录入（优先级高于强度预筛）

用户指定蝶夏Channel、不要脸的狗子的专题作品精灵**全部录入**，不因「强度低／已有上位／娱乐向／PVE 向／无魂印存疑」在录入阶段剔除：

1. 作品清单与精灵编号写入 `references/catalog/creator_index.json`；`roster.json` 的 `creator_coverage.themed_spirit_ids` 为编号全集。
2. 每只专题精灵必须落在 `spirits` 或 `pending_research`，由 `check_roster.py` 强制校验；原 `excluded_examples` 中若有专题精灵，改回候选并注明「全量录入，仍不推荐」。
3. 录入只影响可查性，不改变推荐资格：深研与硬排除照常执行，未过审条目永远标注「待深研」，不得进阵容、梯度或联动结论。
4. 无法程序化抓取的作品写入 `gaps` 说明限制；狗子视频清单经用户决定不再补齐，保留可核验线索即可，禁止凭作者名猜测精灵名单。

## 九、全量图鉴层与人工深研的优先级

`data/bwiki/pool.json` 的 `dropped`（757 条）是**自动构建时的筛选留痕**，不是本技能的删除令：

1. 用户点名、两位指定 UP 主专题作品覆盖、或已人工深研写入 `spirits` 的精灵，即使出现在 `dropped` 中，也**以人工结论为准**，不得删除。
2. 回答「有没有这只精灵」时先查全量图鉴层；`dropped` 命中只说明历史自动筛选留痕（单条魂印／种族值两类已作废），不能据此说「未收录」，更不能据此拒绝录入。
3. 自动 `tier` 只用于排深研优先级（`references/catalog/tier_gaps.json`），当前强度仍以具体月份竞技图鉴和官方限制池为准。
4. **魂印截断已使旧自动判定整体失效**：凡 `references/catalog/soul_text_gaps.json` 与 `references/catalog/voided_drops.json` 中的条目，一律按「先入列表、后深研」重新评估，不得沿用「单条魂印／种族值过低」旧结论；是否重点深研以两位 UP 主作品覆盖为准，仍须核上位替代与当月证据后才可晋升 `spirits`。
5. 全量图鉴层的 1203 只是旧自动规则的构建产物，不是新口径下的收录上限；人工深研层的 133 只是写过战术链的子集。新标准下判断依据是 `creator_index.json`。

### 飞王分支的待核备注

用户明确指出**擎空·凡尔斯（3697）强于混沌飞王凡尔斯（3734）**。魂印原文（976 对 1008）已核验：两者都把速度强化同步到体力、先制上限都是 +5，但 3697 按**己方**阵亡叠加并带高体免异常／低体减伤 50%＋必定弱化，3734 按**对手**阵亡叠加并围绕 300 伤害阈值分支。因此成型可控性不同，属于不同分支而非简单上位替代，两者都保留；默认推荐顺序仍按当季月榜与对位复核，不写死「删除混飞」。同理，洪荒·列奥尼达（4125）属于后续形态且基础／觉醒魂印结算不同，不因「一代精灵王基础形态默认排除」而自动删除。
