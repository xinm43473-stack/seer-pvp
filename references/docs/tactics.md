# 对战思路与精灵联动

所有套路都带资料年份。使用前先核对当前限制池、技能结算和抗性环境；历史套路只说明机制，不承诺当前胜率。

## 一、组队框架

### 1. 冲锋阵

- **骨架**：主突破 + 副突破/收割 + 2 个回合差组件 + 1 个反拦截 + 1 个灵活位。
- **目标**：在对手联防链闭合前拿到第一个人头，再用击杀收益、锁切或消逝阻止回补。
- **常见组件**：4766、3577、3734、4515、4765、3033、4364、3613、4622。
- **失效条件**：首回合送错资源、主 C 吃锁切/消逝、双拦截连续兑掉、对手有免粉免控且高容错的压场核心。

### 2. 联防阵

- **骨架**：2 个不同伤害类型联防 + 反强化 + 消回合/断节奏 + 破局手 + 复活或死亡收益。
- **目标**：不追求每回合收益最大，先让对手的关键技能失效，再用破局手处理资源空窗。
- **常见组件**：3414、3568、3637、3613、3056、2987、4329、3954、3550。
- **失效条件**：重复承担同一伤害类型、没有破局手、所有组件都依赖回合类效果、被锁切后无法换联防。

### 3. 腐蚀阵

- **骨架**：稳定断回合 + 中切 + 可成型的主力 + 2 个拦截/保护 + 属性或抗性补盲。
- **目标**：用断回合和腐蚀差制造额外行动，而不是只靠概率控制。
- **常见组件**：3142、3507、4501、3414、4364、4500、3033。
- **失效条件**：对手高魂免、免断、非回合类启动或能主动送断回合收益的核心。

### 4. 体系阵

- **骨架**：体系发动机 + 体系受益者 + 保护发动机 + 反针对 + 两个通用位。
- **示例**：4800 + 4677，4333 + 4620 + 3613，4125 + 4861/4800，4600 + 4503/4517/4450，4925 + 3430，4661 + 4288，4797 + 4468/3711，4643 + 4648，4126 + 4604/4712/3516，4732 + 反制位，4761 + 需要免秒杀保护的核心。
- **目标**：让体系收益超过占位成本；先确认发动机在场、背包或阵亡时分别给什么收益。
- **失效条件**：发动机被 Ban、被消逝或被对手共享/反用全场效果，受益者与发动机节奏冲突。

### 5. 清 PP 资源阵

- **骨架**：4333 哀·拉伯克（清 PP 主攻）+ 4620 孤烛灯使（PP 形态转换）+ 3613 草王（清 PP 联防/阵亡保护）+ 主动撕裂手 + 返场或反制位 + 灵活位。
- **目标**：先把对手关键技能压到低 PP，再用灯使的低损失分支制造烧伤、全技能归 1、锁先制与锁命中效果，最后由主攻手兑现空窗；不是把 PP 清零就算获胜。
- **成立条件**：能记清对手各项 PP、主动切换灯使，并保留至少一个稳定人头手段；北鸟、莫塔里安、枫眠、密王等按对局补位，不是固定四件套。
- **失效条件**：灯使吸取实际损失达到 10 导致双方回满 PP、首发/死切缺少上只精灵载体、全队只有消耗没有突破，或把锁先制误当成连必先也能封锁。

## 二、当前与高价值联动

### 无极圣武 × 天启星魂（2025 高分段快照）

- **机制（2026-11-07 审核订正）**：4800 位于出战背包时令**双方**精灵登场受到砥砺 1 回合，成功转亮节、未触发转威怯；4677 的结算是星启／星盘／星赐／覆宙星回，**没有「叠层依赖登场砥砺」的条目**。旧文「改善 4677 的叠层环境」无对应结算，双边砥砺属环境效果、可能对己方不利，因此撤销 4800→4677 显式边，本节只作环境说明，不生成同队配合卡片。
- **用法**：先计算 4800 的英雄之耀来源和双方特性构成，再决定星魂何时登场；不要无脑首发叠层。
- **反制**：北鸟直接阻止叠层，梅林拖高层，密王用封属/自爆逼切，古龙惩罚弱化链。
- **版本**：T202510。当前使用前需复核双方是否仍在同一池。

### 薇尔诗位置阵（2026 六月高分段快照）

- **机制**：4000 的魂印按背包首位、末位、相邻、隔位及队友生死变化；阵亡后仍能给存活队友黄金万象。
- **用法**：先排位置，再定路线。进攻时送队友接薇，利用免粉免控与红粉真混伤突破；逆风时用登场双消和阵亡支援稳住。
- **风险**：配置成本高，顶配宝石影响质变；位置错误会损失关键免疫或恢复。
- **记录**：T202606 强调她不是只看单卡强度，而是位置资源与队伍顺序的放大器。

### 伞邪双诛魔：尤莉米特 × 圣谕邪魇（按当前魂印复核，体系成立但难以上场）

- **两段「诛魔」各是什么**：
  - **第一段来自尤莉米特**：SA:1588（当前生效版，`desc_formatting_adjustment` 为游戏内结算文本）的群辉加护在**自身被击败时**消耗全部层数，每层让所有不在场精灵所有技能回 1 PP，并让**下只精灵登场后首次技能附加「群芳加护消失时所受攻击伤害 20%」的百分比伤害**（累计 20%×层数）。注意 4364 在 SeerAPI 有两条 soulmark：**1588 是带格式化文本的当前版，2080 是只有 `desc` 的旧版**（双方受 1 点固伤／吸血）；按文本长度判新旧会把 2080 误认成当前版，规则已改为 `has_format` 优先。BWIKI 网页版与 1588 一致。
  - **第二段来自技能「诛魔杀阵」**：SK:17908，圣光灵神（3311，远古圣灵物理攻击、威力 80、先制 +3、PP 10）的技能，三段效果为**附加对手上次造成伤害数值的固定伤害**／下 2 回合自身攻击伤害翻倍／遇到天敌时先制 +1。它不是尤莉米特的魂印，也不是她本人能带的技能；需要 3311 作为第三只挂件提供。官方 CLI 复核：`pet:3311` 技能表 31 条中确有 17908；`skill:17908` 的 `learned_by_pet` 反查为空属于 API 索引缺口，归属须由 `pet.skill` 正查确认。
- **收口**：4554 圣谕邪魇第五（击败对手则令对手下一次攻击技能无效）在双段附加伤害兑现击杀后封住对手反打，这就是「双诛魔」的完整链。
- **顺序**：先让尤莉米特在需要的位置登场叠群辉 → 被攻击技能命中后群芳加护消失、锁切锁先制 → 送掉伞，死亡传承给下只精灵首次技能附加 20%×层数 → 紧接邪魇登场，首次技能同时吃两段附加伤害 → 第五拿击杀并封对手下次攻击。
- **失效**：对手不杀伞（拿不到死亡传承）、封属／控住伞不让其正常登场叠层、免粉与锁伤吃掉百分比、先消传承、邪魇被更高先制或抗性拦截；3311 占一个位置本身也是成本。
- **为什么难以上场**：这条链要求三只位置（4364＋4554＋3311）、要求对手配合击杀伞、还怕当前环境常见的封属与免粉；用户 2026-11-06 明确「体系确实存在，只是由于策划针对难以竞技上场」，所以登记为**成立但非主流**，不当稳定上分推荐。
- **变体**：旧版正文写「也可接 4765 或 3577」，接棒位可以换，但两段诛魔的来源不变；斩杀线与弹伤风险各不同。

### 武心婵龙鳞管理（2024）

- **机制**：4500 的红鳞挡红伤并断回合，黄鳞处理控制，蓝鳞处理弱化；三色首次耗尽进入白鳞阶段，强化可重新获得龙鳞。
- **进攻**：先三勇人取得控制窗口，再强化与 150 推进；白鳞最后一回合附近规划第五解鳞。
- **腐蚀**：可带红之初醒，主动利用红鳞被破的断回合制造回合差。
- **非腐蚀**：蓝之初释更常用于主动处理不方便被破的蓝鳞。
- **风险**：闪避、魂免、断回合和跳过龙鳞交互的伤害。

### 空元行者技能栏与二段资源（2024）

- **机制**：4586 将阵亡精灵转化为体力上限与魂印层数，二段技能消耗层数；技能所在栏位决定对应二段收益。
- **常用摆位**：强化、免控、150、先手。强化二段锁切，免控二段传承次免，150 二段处理明佛，先手二段双消与诅咒。
- **用法**：后场层数充足时做强杀或收割；死切成型敌人时先确认能安全吃到关键资源。
- **失败条件**：前排白送但没有换到层数价值、层数不足以支撑关键二段、对手利用锁切反逼空元。

### 圣耀天马反强化（2024）

- **机制**：3670 根据对手强化是否增加获得免红伤或华冠先制等收益，擅长惩罚强化流。
- **应对天马**：不要随意叠强化送其触发；可用自然石、机盖或高稳定弹伤直接处理。
- **使用天马**：观察对手强化是否真实生效，再选择中切；配合先制与混合伤害打信息差。

- **关键**：不要把琉梦只当“咤克斯补丁”，双方资源交换会随希望之花是否被摧毁而反转。

- **版本**：T202506/T202508。

### 斯布林蒂 × 库坦：PP 同步爆发（2024 体系复盘，后续月榜仍有对位记录）

### 低体秒杀的两条路径：星域之魂 × 米罗博士（不是固定体系）

这一节登记的是**等效替代关系**，不是同队联动。两者都用「极低血量换一次必杀」，但一条靠自己进血线，一条靠消逝自己把队友拉成 1 血；把它们写成固定配合会掩盖各自的成本。

- **3430 星域之魂**：回合开始低于 30% 体力时全技能秒杀，随后清空全部 PP 并消除自身回合类效果。触发只依赖自身血线——主动控血、被对手压血、或被任何「1 血复活」拉回都能进入。秒杀后 PP 全空，需要活力保留宝石或队友接棒。
- **4925 米罗博士**：第五「太古的至宝」先制 +1，消耗自身全部体力、消逝自己，令己方场下**首位**已阵亡精灵以 1 点体力复活。这是「用一条命造一个 1 血单位」，复活目标由阵亡顺序决定、不能指定；被拉回者必须自带低体收益才兑现秒杀，否则只是一次返场。米罗消逝后不能重复利用。
- **为什么不登记为体系**：两者不是机制互相放大，而是同一目标的两种实现；同队只在「星域恰为场下首位阵亡」时成立，且这条衔接可被阵亡顺序、封属、控场、返场即被更高先制处理打断。把它写成稳定体系，等于把一次性兑子说成常规组合。
- **什么时候才考虑同队**：需要「星域已阵亡且复活位无错位」＋「米罗能安全用出第五」＋「对手没有免秒杀或稳定拦截」三个条件同时成立；缺一个就按二选一处理，星域自己控血更省资源。
- **单只补强**：4861 涂蝶、4364 尤莉米特用于处理莫妮卡、苍月等高先制威胁；活力保留只增加返场可能，不等于必定再启动。
- **证据**：W:3430、W:4925、SK:29409 验证机制，V2026STARS 提供星域单核实战摘要；未找到完整同队对局前不标「稳定主流」。旧版曾把本条写成「米罗星域一血体系」，2026-11-06 已从体系表移出，改为 `role_groups.json#low_hp_execution`。

### 无为觉者 × 龙仪·机械塔克林（2025—2026 月榜）

- **机制**：4661 依靠 PP 反转、零 PP 技能和击败后的群体消逝滚资源；4288 提供中切庇护和返场窗口。
- **顺序**：龙塔承接高压回合 → 无为安全中切 → 调整 PP 触发反转/强制执行 → 逐项解除第五限制 → 拿击杀后处理对方阵亡资源。
- **失败**：无为被迫在无庇护时硬切、PP 被对手反向利用、第五限制未解就僵化出招、龙塔庇护被消逝或回合差绕开。

## 四、BP 与对位检查清单

1. **先算池位**：禁止、限制、准限制分别占位，先保证核心战术能合法成型，再讨论强度。
2. **每队至少一项主动破局**：只靠联防耗时不等于有赢法；确定由谁拿第一个人头或第一波资源差。
3. **双消覆盖**：消回合与消强化最好不绑在同一时点；对手有免断时准备第二方案。
4. **红粉真覆盖**：至少识别队伍主要伤害类型，避免六个位置同时被免红或免粉关掉。
5. **死亡链检查**：逐一问“这人死了给对面什么、给己方什么、能否被复活/消逝/曝影响”。
6. **抗性不是万能**：睡眠、害怕等抗性只提高容错，不改变机制克制；不要把 55 抗当必胜条件。
7. **套装联动**：晨曦、裁决、影翼、腐蚀等会改变首发、速度和承伤模型；不同套装下的梯度不可直接混用。
8. **对位写失效条件**：每个推荐同时写“对手怎么破解”，没有反制路线的结论通常是资料不足。
